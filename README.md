## 🛰️ Architecture & Structure

The portfolio is structured as a continuous spatial voyage across 6 sectors:

1. **Hero**: Gravitational opening shot with dynamic scale typography and orbital axis signals.
2. **About**: Academic foundation at Foreign Trade University, institutional workflows, and telemetry metrics.
3. **Experience**: Orbital trajectory spine highlighting key milestones:
   * **VPBank** — Wholesale Banking Operations Intern (Treasury & Trade Finance)
   * **MB Bank** — Universal Banker Intern (Retail banking & digital adoption)
   * **U2U** — Business Development Intern / Associate (Fintech product benchmarking)
   * **TEC FTU** — Product & Communications Lead
4. **Selected Work**:
   * **Cardy**: Interactive credit card recommendation platform with 3D tactile card tilt and goal-based simulation.
   * **Credit Risk Model Stability**: Variable retention analysis across ~20M records using WoE / IV and Gini / AUC evaluation.
   * **Reading Vietnamese Banks**: Comparative balance-sheet analysis of 27 commercial banks over 5 years (NPL, LLCR, LDR, CASA).
5. **Background**: Curricular focus (*Applied Technology in Finance & Banking*, *Fintech*, *International Financial Management*), key distinctions, and skills quadrant.
6. **Contact**: Minimal transmission horizon with one-click email copy.

## 🎬 Cinematic Highlights

* **27-Second Prologue**: An 8-phase cinematic opening sequence (Absolute Darkness → Distant Universe → Movement Through Space → Light & Gravity → Name Reveal → Identity → The System Climax → Arrival).
* **Procedural Ambient Drone**: Built-in Web Audio API sub-bass drone synthesizer (55 Hz / 82.5 Hz harmonic oscillation with lowpass LFO filter modulation) requiring zero external audio assets.
* **Continuous 3D Starfield**: Canvas engine rendering spatial stars with real-time perspective projection, motion streaks, and scroll-linked depth translation.
* **Skip & Replay Controls**: Unobtrusive `Skip Sequence ⇥` and `Prologue ↺` buttons with `sessionStorage` persistence and reduced-motion support.

## 🚀 Local Development

To run the site locally:

```bash
# Clone the repository
git clone https://github.com/gitoutofnowhere/portfolio.git

# Navigate into the project folder
cd portfolio

# Start a local static file server (Python 3)
python -m http.server 3000
```

Open your browser at `http://localhost:3000`.
